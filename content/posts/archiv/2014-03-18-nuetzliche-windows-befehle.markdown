Für den schnellen Gebrauch kann es sinnvoll und um einiges schneller sein, Befehle in Ausführen (`Windows + R`) einzugeben als umständlich über das Start-Menü und Einstellungen zu suchen.

<!--more-->

{{< archiv-note >}}

| **Programm**                                | **Befehl**   |
|---------------------------------------------|--------------|
| Computerverwaltung                          | compmgmt.msc |
| Dienste                                     | services.msc |
| Eingabeaufforderung                         | cmd.exe      |
| Ereignisanzeige                             | eventvwr.msc |
| Freigegebene Ordner                         | fsmgmt.msc   |
| Gruppenrichtlinieneditor                    | gpedit.msc   |
| Internet Explorer                           | iexplore.exe |
| Rechner                                     | calc.exe     |
| Registrierungs-Editor                       | regedit.exe  |
| Windows-Explorer                            | explorer.exe |
| Windows-Firewall mit erweiterter Sicherheit | wf.msc       |
| Alte Systemsteuerung                        | control.exe  |

Parameter für die Systemsteuerung (`control.exe` parameter)

| **parameter**                          | **Fehler**                               |
|----------------------------------------|------------------------------------------|
| appwiz.cpl                             | Programme und Features                   |
| UserPassword2                          | Fenster *Benutzerkonten*                 |
| Modem.cpl oder telephon.cpl            | Telefon und Modem                        |
| admintools                             | Verwaltung                               |
| /name Microsoft.BackupAndRestoreCenter | Sichern und Wiederherstellen (Windows 7) |
